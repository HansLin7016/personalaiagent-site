名片助理 隱私權政策

最後更新：2026 年 11 月 18 日

一、適用範圍

本政策說明公司內部 AI 助理的「名片助理」功能（以下稱「本服務」）如何蒐集、使用、保存使用者資料。本服務僅供公司內部同仁使用。

二、蒐集的資料

  • 同仁主動傳送的名片照片，以及從名片辨識出的聯絡資訊（姓名、公司、職稱、電話、電子郵件、地址等）。
  • 同仁在通訊軟體中的帳號識別碼（用於辨識使用者與權限）。
  • 經同仁授權後取得的 Google 帳號存取權杖，僅用於將名片新增到該同仁的 Google 通訊錄。

三、Google 使用者資料的使用

本服務透過 Google People API 取得 https://www.googleapis.com/auth/contacts 權限，用途僅限於：

  • 在同仁本人的 Google 通訊錄中「新增」由其傳送的名片聯絡人，並建立「名片助理」聯絡人群組。

本服務不會讀取、分析、修改或刪除使用者既有的聯絡人；不會將 Google 使用者資料出售、轉讓或提供給第三方；不會用於廣告；也不會用於訓練人工智慧或機器學習模型。

本服務對於從 Google API 取得之資訊的使用與傳輸，遵守 Google API 服務使用者資料政策，包括「有限使用」（Limited Use）要求。

四、資料處理與保存

  • 名片資料保存在公司自行管理的伺服器，僅供公司內部依權限查閱。
  • Google 存取權杖以加密方式保存，僅用於新增聯絡人。
  • 名片辨識使用 Anthropic 公司的 Claude API 處理影像與文字，該處理僅用於產生辨識結果。

五、使用者權利與撤銷授權

  • 同仁可隨時在助理中傳送 /google_off 停用同步，系統即刪除所保存的 Google 存取權杖。
  • 也可至 Google 帳戶「第三方連結」 移除本服務的存取權。
  • 如需查詢或刪除已建檔的名片資料，請洽公司內部系統管理者。

六、聯絡方式

對本政策有任何疑問，請洽公司內部系統管理者。

七、政策更新

本政策如有修改，將更新於本頁並註明更新日期。
